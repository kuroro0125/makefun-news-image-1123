One page that sums up Monday 23 November 2026: COP31 ending with no
deal after two days of overtime, the Democrats clinching a historic
House majority of at least 258 seats, Russian strikes killing 11
across the Kyiv region, a candy factory fire in Indonesia leaving 3
dead and dozens missing, and Delta delays piling up before
Thanksgiving — plus a six-line ALSO TODAY strip (Seoul, Washington,
Tehran, Pyongyang, Khartoum, BepiColombo at Mercury).

`entry.png` is rendered by `render23.py` (Pillow, deterministic — same
bytes on every run) from that day's wire and newspaper headlines (AFP,
AP, Reuters, Xinhua). `main.py` copies the bundled sheet into the
output directory the harness points at.

## Run it

```sh
python3 main.py
```
