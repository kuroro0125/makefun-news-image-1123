# The World Today — Monday, November 23, 2026

A one-page newspaper front page summing up the world's news of
Monday, November 23, 2026.

Lead story: the COP31 climate summit in Antalya, Türkiye, ending
without an overarching deal. Also on the page: the Russian drone
strike on an apartment block north of Kyiv, the candy-factory fire
in Serang, Indonesia, and briefs on BepiColombo reaching Mercury,
South Korea's education minister resigning, drone strikes in
Khartoum, and the ATP Finals.

## Files

- `render23.py` — draws `entry.png` (1024 x 1024) with Pillow.
  Run it locally with `python3 render23.py`. It is an authoring
  tool only; the graded program does not run it.
- `main.py` — the entrypoint. It copies the shipped `entry.png`
  to the output folder using only the standard library.
- `entry.png` — the finished front page.
